# Crawler Final Kit 使用规则

## 总原则

OpenClaw 在执行数据采集任务时，必须以公开、低频、可审计、可停止为原则。

## 任务前检查

每次采集前必须输出：

1. 采集目标。
2. 目标 URL。
3. 是否公开可访问。
4. 是否需要账号、验证码或付费权限。
5. 是否存在公开 API / RSS / Sitemap。
6. robots.txt 检查结果。
7. 采集字段。
8. 最大采集页数。
9. 请求间隔。
10. 输出路径。

## 停止条件

遇到以下情况立即停止，并生成风险报告：

1. HTTP 403。
2. HTTP 429。
3. 登录页。
4. 验证码页。
5. 付费页。
6. 隐私内容。
7. robots.txt 明确不允许。
8. 连续 2 次请求失败。
9. 目标域名不在 allowed_domains。

## 输出要求

每次任务必须生成：

1. JSON 结果。
2. CSV 结果。
3. Excel 结果。
4. Markdown 报告。
5. 日志文件。

## OpenClaw 指令模板

```text
进入公开数据采集工程模式。
目标 URL：
采集字段：标题、正文摘要、链接。
最大页数：20。
请求间隔：2 秒。
输出目录：C:\OpenClawWork\Crawler_Final\output。
要求：先检查 robots.txt，遇到 403/429/登录页/验证码页/付费页立即停止。
```
